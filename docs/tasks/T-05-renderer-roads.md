# T-05. Рендер полотна из сети

**Пакет:** `apps/web` · **Волна:** 1 · **Уровень:** M · **Размер:** ~900 строк · **Зависит от:** — (данные: `straightRoad`-подобный JSON или сеть из T-02) · **Разблокирует:** T-13, T-25, T-27

## Цель
Three.js-сцена, которая по `Network` строит полотно дорог с разметкой: полосы, штриховые и сплошные линии,
карманы, выделенки (цвет и буква «А»), стрелки в поворотных полосах, стоп-линии, зебры. Камера с орбитой, WASD,
подписи улиц. Без машин (T-13).

## Контекст
`CLAUDE.md` (координаты: `(x, y) → (x, 0, -y)`); `docs/CONTRACTS.md` («Конвенция геометрии полос»);
`packages/contracts/src/network.ts`; `docs/DECISIONS.md` D13 (low-poly, без теней, приглушённая палитра).

## Контракты
Только потребляет `Network`. Ничего не считает про движение.

## Что сделать
1. `scene/renderer.ts`: `WebGLRenderer`, `PerspectiveCamera`, `OrbitControls` (`three/addons`), полусферический +
   направленный свет без теней, resize, `requestAnimationFrame`-цикл с колбэками `onFrame(dt)`.
2. `scene/roads.ts`: по каждому линку — лента полос: центр полосы `i` = осевая, смещённая вправо на
   `(i − (N−1)/2)·width`, ширина 3,5 м, только на `[startS, endS]` полосы. Одна `BufferGeometry` на класс поверхности
   (общая, выделенка, карман), цвета через vertex colors. Разметка отдельной геометрией чуть выше полотна:
   штрих 3 м/пробел 3 м между полосами, сплошная по краям и вдоль выделенки, буква «А» повторяющимся спрайтом-текстурой
   (сгенерировать canvas-текстуру), стрелки по `turns` в последних 20 м полосы (треугольники + прямоугольник),
   стоп-линии на конце полос перед узлами `signalized`, зебры по `crosswalks.geometry`.
3. Коннекторы: тонкая полупрозрачная лента по `geometry` (видно, куда ведут движения), выключается флагом.
4. `scene/labels.ts`: `CSS2DRenderer`, подписи имён линков классов trunk/primary/secondary в середине линка,
   видимость по расстоянию камеры.
5. `scene/camera.ts`: пресеты `overview(bbox)` и `focus(x, y, radius)` с плавным перелётом (`lerp` по времени),
   WASD-панорамирование, ограничение наклона.
6. Загрузка сети: `data/loadNetwork.ts` — `fetch('/networks/<id>.network.json.gz')` + `DecompressionStream('gzip')`
   + `parseNetwork`. Скрипт `apps/web/scripts/copy-networks.mjs` копирует `data/networks/*.gz` в `apps/web/public/networks/`
   (вызывается в `predev`/`prebuild`). Если файлов нет, приложение показывает `straightRoad`-подобную сеть из
   `src/data/demo-network.ts` (сгенерированную в коде, чтобы демо запускалось без данных).
7. Заменить `App.tsx`-заглушку на канвас на весь экран + тонкий верхний бар с названием и атрибуцией ODbL.
8. Тесты (vitest, node): математика смещения полос, сборка геометрии для `straightRoad` даёт ожидаемое число вершин,
   стрелки по `turns`. Визуальная проверка: скриншот `pnpm dev` приложить в отчёт (описанием).

## Заметки от T-10 (учесть)
- `BLINKER_LEFT`/`BLINKER_RIGHT` — пошаговые флаги в кадре, горят ровно 2 с манёвра; поперечное смещение уже
  проинтерполировано в `x`/`y`, отдельной анимации перестроения на клиенте не нужно.
- Манёвр обрывается при переходе полоса → коннектор (`advanceTrack` обнуляет `laneChangeEndS`): у самой
  стоп-линии машина может «щёлкнуть» на ось полосы. Если это заметно, чинить надо в ядре, а не в рендере.
