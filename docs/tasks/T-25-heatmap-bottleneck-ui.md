# T-25. Тепловая карта и панель узких мест

**Пакет:** `apps/web` · **Волна:** 5 · **Уровень:** M · **Размер:** ~1000 строк · **Зависит от:** T-19, T-23 · **Разблокирует:** T-26

## Цель
Окраска полотна по скорости из `MetricsFrame`, список Топ-N с причинами и рекомендациями, маркеры над узкими
местами, подлёт камеры, спарклайн задержки, миникарта.

## Контекст
`packages/contracts/src/metrics.ts` (`MetricsFrame`, `BottleneckReport`, `SegmentDescriptor`); T-05 (геометрия полос,
камера `focus`); T-19 (`recommendations.overrides`); `docs/DECISIONS.md` D11, D13; палитра: зелёный → жёлтый → красный
приглушённые, читаемые на сером полотне; при `speedRatio` без данных — серый.

## Что сделать
1. `scene/heatmap.ts`: атрибут цвета на геометрии сегментов (T-05 строит полосы; разбить ленты по сегментам 25 м или
   добавить отдельную геометрию сегментов поверх полотна). Режимы: «сейчас» (последний семпл — из кадра: средняя скорость
   машин на сегменте считается в воркере? Нет: использовать `speedRatio` окна и отдельный короткий режим не делать; режимы
   «окно 5 мин» и «выкл»). Легенда цветов.
2. Вкладка «Узкие места»: таблица Топ-N (ранг, название, задержка маш-ч/чел-ч, переключатель сортировки, LOS-бейдж, V/C),
   раскрытие строки: полоса долей причин с подписями `CAUSES.ru`, рекомендации кнопками «Применить в сценарии» (создаёт
   override через T-24 API) и «Показать».
3. Маркеры: CSS2D над `focus` с номером ранга и цветом по LOS; клик = выбор строки + `camera.focus`.
4. Спарклайн суммарной задержки за последние 30 минут (canvas 2D, без библиотек) и число активных узких мест.
5. Миникарта: canvas 2D с линками, окрашенными по `speedRatio`, прямоугольник видимой области, клик = перелёт.
6. Тесты: маппинг `speedRatio → цвет`, сортировка/фильтрация отчёта, спарклайн-буфер.

## Файлы
`apps/web/src/scene/{heatmap,markers}.ts`, `src/ui/{BottlenecksTab,CauseBar,Sparkline,Minimap}.tsx`, тесты.

## Критерии приёмки
- [ ] На маленьком квадрате в 08:00 виден Топ-10 с причинами, подлёт работает; `pnpm check` зелёный; тепловая карта не ломает 60 fps.

## Заметки из ревью T-05 (учесть)
- Базовый меш полотна (`surface-*`) окрашен одним vertex-color на полосу и по 25-метровым сегментам не делится. Тепловую карту строить отдельным слоем-оверлеем по сегментам из `SegmentDescriptor[]` теми же примитивами `slicePolyline` / `buildRibbonGeometry` / `mergeRibbons` из `scene/ribbon.ts` и `geometry/lane-geometry.ts`, чуть выше полотна, не трогая `roads.ts`.
- Пересборка `s → (x, y, heading)`: `sampleAtS` + `laneAxis` в `geometry/lane-geometry.ts`, без зависимости от sim-core (важно и для T-13).
