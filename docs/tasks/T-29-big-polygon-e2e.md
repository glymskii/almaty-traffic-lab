# T-29. Большой полигон end-to-end и QA генератора

**Пакет:** все · **Волна:** 6 · **Уровень:** S · **Размер:** ~600 строк · **Зависит от:** T-17, T-27, T-28 · **Разблокирует:** T-31

## Цель
Импорт, компиляция и прогон большого полигона (Райымбека–Аль-Фараби × Гагарина–Достык): 407 сигнализированных узлов,
~2 850 way, развязки. Найти и починить крайние случаи генератора, зафиксировать QA-отчёт.

## Что сделать
1. `pnpm run import --bbox big` (если снимок не закоммичен в T-01, закоммитить; при > 60 МБ предложить LFS в отчёте).
2. `pnpm run compile --bbox big`: собрать список предупреждений и падений, исправить компилятор (типовые проблемы: неразборные
   `turn:lanes`, way с одним узлом, самопересечения, `layer` без `bridge`, дубли `traffic_signals`, кольца `junction=roundabout`,
   маршруты ОТ с петлями). Каждый фикс с тестом на минимальной фикстуре.
3. QA генератора: выборка 20 случайных сигнализированных узлов, для каждого краткая проверка плана (число фаз, цикл, стрелки
   там, где карманы) — таблица в `docs/QA-big.md`; правила-предохранители в генераторе (например, не более 6 фаз, цикл ≤ 120).
4. `pnpm sim --bbox big --minutes 30 --seed 1`: отчёт Топ-10 в `docs/QA-big.md` с комментарием, правдоподобно ли
   (совпадения с известными проблемными местами отметить, но не подгонять).
5. Проверка в браузере: загрузка сети < 5 с, прогрев 10 мин < 60 с, 60 fps, `rtFactor ≥ 1` при бюджете 20 000.
6. Закоммитить `data/networks/almaty-center-big.network.json.gz` и `.assumptions.json`.

## Критерии приёмки
- [ ] Компиляция большого полигона без ошибок integrity; `docs/QA-big.md`; `pnpm check` зелёный.
