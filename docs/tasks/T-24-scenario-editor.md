# T-24. Редактор сценариев и применение overrides

**Пакет:** `packages/map-data` + `apps/web` · **Волна:** 5 · **Уровень:** M · **Размер:** ~1100 строк · **Зависит от:** T-08, T-23 · **Разблокирует:** T-26

## Цель
`applyOverrides(network, overrides, config)` в `map-data` и UI-формы редактирования перекрёстка, участка и
глобальных параметров; сценарии хранятся в localStorage, экспортируются/импортируются JSON; применение =
перекомпиляция + перезапуск с тем же сидом.

## Контекст
`docs/CONTRACTS.md` («Scenario и overrides»); `packages/contracts/src/overrides.ts`; T-07 (функции перестроения
коннекторов узла), T-08 (`regenerateController`); `docs/DECISIONS.md` D12.

## Что сделать
1. `map-data/src/compiler/overrides.ts`: применение по видам:
   - `link`: пересобрать полосы линка (`generalLanes`, карманы с длинами, `busLane` добавить/убрать/изменить, `speedLimitKph`),
     затем пересобрать коннекторы и конфликты на обоих узлах линка (T-07) и контроллеры этих узлов (T-08), сохранив ручные
     параметры контроллеров, если для них есть `signal`-overrides; provenance `manual`;
   - `signal`: `regenerateController`; `bus_stop`, `bus_route` (`enabled: false` удаляет маршрут);
   - результат: новая `Network` (исходная не мутируется), `meta.networkId = <base>+<scenarioId>`, integrity обязателен.
   Экспорт `applyOverrides` из `@atl/map-data` (браузерная сборка: без node-модулей в этом пути).
2. UI: клик по узлу `signalized` → форма: по подходам тип левого поворота, зелёные секунды групп, цикл, смещение, пешеходная
   фаза; клик по линку → форма: сквозные полосы, скорость, левый/правый карман, выделенка (вкл, часы, окно правого поворота),
   остановки на линке (в полосе/карман). Кнопка «Применить» создаёт/обновляет override в текущем сценарии.
3. Вкладка «Сценарии»: список, создать/копировать/удалить/переименовать, активный сценарий, кнопка «Запустить» (перекомпиляция
   в главном потоке с индикатором, затем новый воркер с тем же сидом), экспорт JSON, импорт с валидацией `ScenarioSchema`
   и проверкой `networkId`.
4. Подсветка изменённых объектов на карте (контур).
5. Тесты (`map-data`): каждый вид override на `crossroads`/`straightRoad`: integrity пустой, детерминизм, идемпотентность
   (повторное применение того же override не меняет результат), `busLane: null` убирает полосу и коннекторы; UI: редьюсеры
   сценариев и сериализация localStorage.

## Файлы
`packages/map-data/src/compiler/overrides.ts` (+ тесты), `apps/web/src/ui/{ScenariosTab,IntersectionForm,LinkForm}.tsx`,
