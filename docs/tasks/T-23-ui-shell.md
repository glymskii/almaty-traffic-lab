# T-23. Оболочка UI

**Пакет:** `apps/web` · **Волна:** 5 · **Уровень:** C · **Размер:** ~800 строк · **Зависит от:** T-13 · **Разблокирует:** T-24, T-25, T-30

## Цель
React-оболочка вокруг сцены: раскладка, управление временем, пресеты времени суток, глобальные параметры,
HUD, загрузка сети и прогрев, атрибуция, легенда допущений, все строки в `i18n/ru.ts`.

## Контекст
`docs/DECISIONS.md` D2, D12; `packages/contracts/src/sim-config.ts` (`RUNTIME_SAFE_PARAM_PATHS`, дефолты);
`packages/sim-worker` (`SimClient`); T-13 подключение клиента; `CLAUDE.md` правило 7 (i18n).

## Что сделать
1. Раскладка: канвас на весь экран; слева панель с вкладками «Обзор», «Узкие места» (T-25), «Сценарии» (T-24),
   «Сравнение» (T-26); снизу бар управления временем; справа сверху HUD. Компоненты в `src/ui/`, состояние через
   лёгкий стор (`zustand` допустим как единственная новая зависимость, иначе `useSyncExternalStore`).
2. Управление временем: play/pause, скорость 1×/2×/5×/10×, часы симуляции, кнопка «Перезапуск». Пресеты
   «Утро 08:00», «День 14:00», «Вечер 18:30» = перезапуск с `startTimeMin` и прогревом (прогресс-бар).
3. Глобальные параметры: слайдеры множителя спроса, доли навигаторов, дисциплины, нарушителей — применяются на лету
   через `setParams`; остальные (бюджет машин, интервалы автобусов, такси в выделенке) с пометкой «требует перезапуск».
4. HUD: машин активных/бюджет, `rtFactor` (жёлтый < 0.8, красный < 0.5) с подсказкой «снизьте бюджет», fps,
   средняя скорость, задержка за окно. Обновление из `metrics`/`report`.
5. Загрузка: выбор сети (`small`/`big`) из `public/networks/`, базовый сценарий, `init` → `runUntil(прогрев)` → `play`.
6. Легенда допущений: доля атрибутов `default` по категориям (считается из `provenance` сети) во вкладке «Обзор» с текстом
   «Данные условные: OSM + допущения генератора».
7. Атрибуция ODbL в углу; тултипы при наведении на перекрёсток/улицу (имя, класс, полосы, скорость и происхождение) —
   raycast по полотну, показ в CSS2D.
8. Тесты: редьюсеры стора, форматирование времени, расчёт доли допущений; smoke-рендер компонентов с `@testing-library/react`
   (добавить dev-зависимость) для панели времени.

## Заметки из ревью T-05 (учесть)
- `Viewport` после правок T-05 отдаёт `onReady({ engine, rig, network })`: через него панели фокусируют камеру, переключают слои (коннекторы, здания) и подписываются на кадры. Не лезть в сцену напрямую из React.
- Кнопка «Обзор» использует `rig.overview()` с плавным перелётом.
- Файлы сетей называются по id пресета (`almaty-abay-small`, `almaty-center-big`), а не по ключу (`small`/`big`): переключатель сети должен брать `BBOXES[key].id` из `@atl/map-data` (добавить зависимость) или дублировать таблицу id в web.
