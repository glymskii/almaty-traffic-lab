# T-13. Рендер машин, светофоров и пешеходов

**Пакет:** `apps/web` · **Волна:** 2 · **Уровень:** M · **Размер:** ~800 строк · **Зависит от:** T-05, T-06 · **Разблокирует:** T-23

## Цель
Из `FrameBuffers` рисовать машины инстансами с интерполяцией между кадрами, стоп-сигналами и поворотниками;
светофорные головки с состояниями секций; пешеходов точками на зебрах. Это веха M1/M2 визуально.

## Контекст
`packages/contracts/src/state.ts` (`FrameBuffers`, `VehicleFlag`, `SignalState`, коды классов);
`packages/sim-worker` (`createSimClient`, `createStubSimulation`); T-05 сцена; `docs/DECISIONS.md` D13.

## Что сделать
1. `scene/vehicles.ts`: `InstancedMesh` на класс (легковая: два бокса «кузов+кабина», автобус: длинный бокс, троллейбус:
   бокс + две штанги, такси: легковая жёлтая). Ёмкость = `vehicleCapacity` из `ready`. Цвет через `instanceColor`
   (палитра легковых из 6 приглушённых цветов по `id % 6`). Стоп-сигналы: маленький красный инстанс сзади при `BRAKING`;
   поворотники мигают 2 Гц при `BLINKER_*`. Скрытие неиспользуемых инстансов масштабом 0.
2. Интерполяция: хранить два последних кадра, по `id` строить карту слот→позиция (Map допустим на главном потоке, но
   лучше `Int32Array` по `id`, если `id` ограничен ёмкостью: `id = slot + generation·capacity`, взять `id % capacity`);
   позиция = lerp по времени между кадрами, heading через кратчайший угол.
3. `scene/signals.ts`: для каждой сигнальной группы столб + головка у стоп-линии подхода (позиция: конец первой полосы
   группы, смещение вправо на 2 м); основная секция: три лампы; `arrow_left/right`: дополнительная лампа со стрелкой сбоку.
   Цвета по `SignalState`, мигание для `FLASHING_GREEN`, `OFF` = тёмная. Инстансы ламп, обновление цвета из `signalStates`.
4. `scene/pedestrians.ts`: по `crosswalkPeds[i]` рисовать `n` точек, равномерно вдоль зебры (инстансы сфер r=0,3).
5. Подключить `SimClient` в приложении: `init` с сетью (демо-сеть или загруженная), `runUntil` прогрева с прогресс-баром,
   `play(1)`; на `onFrame` обновлять инстансы. Пока нет T-04 в `main`, использовать `createStubSimulation` через флаг.
6. Тесты: интерполяция углов и позиций; раскладка цветов; сборка головки светофора для группы.

## Файлы
`apps/web/src/scene/{vehicles,signals,pedestrians,interpolation}.ts`, `src/sim/client.ts`, тесты.

## Критерии приёмки
- [ ] 20 000 инстансов при 60 fps на этой машине (стресс-режим со стабом).
- [ ] Стоп-сигналы и поворотники видны; секции светофора различимы; `pnpm check` зелёный.

## Вне объёма
UI-панели (T-23), тепловая карта (T-25), здания (T-27).

## Заметки от T-06 (учесть)
- Временная страница `apps/web/src/DebugWorkerView.tsx` и проверка `?debug=worker` в `App.tsx` удаляются в этой задаче.
- Воркер поддерживает `?sim=stub` в URL для заглушки-симуляции (`createStubSimulation` из `@atl/sim-worker`).
- Позиция машины по `s`: `sampleAtS`/`laneAxis` из `apps/web/src/geometry/lane-geometry.ts` (если кадр несёт x/y/heading, они уже посчитаны ядром; использовать их напрямую, геометрию полос не пересчитывать).
